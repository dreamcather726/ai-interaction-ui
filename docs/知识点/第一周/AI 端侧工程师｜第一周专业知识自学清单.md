本周主要学习数字音频处理和自动语音识别的相关知识，理解录音文件如何被计算机读取，以及本地 ASR 模型如何将音频转换为文字。

完成学习后，应能够理解本次项目使用的音频格式、ASR 模型的基本工作过程，并具备独立查阅技术文档、部署模型和分析常见问题的能力。

本清单不重复安排 ROS2 公共基础知识，也不要求单独开发练习项目。

## 三、需要自主研究的问题

请结合查阅的资料，使用自己的语言回答。

### 数字音频

1. 什么是采样率？16 kHz 代表什么意思？

2. 什么是采样位深？16\-bit PCM 代表什么？

3. PCM 和 WAV 有什么区别？

4. 为什么本项目要求使用 16 kHz、16\-bit、单声道音频？

5. 如果收到的是 48 kHz 双声道音频，应该如何转换？

6. 为什么不能仅通过修改文件扩展名或采样率标记来完成音频转换？

### ASR 语音识别

1. ASR 是什么？它的输入和输出分别是什么？

2. ASR 模型是如何将语音转换成文字的？

3. Whisper 和 FunASR 分别是什么？有哪些主要特点？

4. 什么是模型推理？它和模型训练有什么区别？

5. 为什么不同录音的识别效果可能不一样？

6. 为什么输入音频格式不正确可能影响识别结果？

### 模型部署与程序开发

1. 什么是模型权重？本地模型为什么需要模型文件？

2. CPU 推理和 GPU 推理有什么区别？

3. 为什么模型通常应该初始化一次，然后复用？

4. 如果音频文件不存在，程序应该如何处理？

5. 为什么需要记录日志和保存识别结果？
