## 一、学习目标

本周主要学习 Python 图形用户界面（GUI）开发的基础知识，理解桌面应用程序的组成、图形界面的工作原理以及动态数据更新的基本方法。

通过本周学习，掌握 PySide6 的基础控件、界面布局、事件循环与定时器等知识，理解如何将外部数据转换为用户能够直观观察的界面信息。

结合本次研发任务，实现机器人语音识别状态和识别文字的可视化展示，理解状态变化、数据更新、数据中断和界面响应之间的关系。

为后续机器人运行状态、SLAM 地图、导航状态及摄像头视频流可视化开发建立基础。
