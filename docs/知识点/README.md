## 二、怎样学习

1. 阅读知识点和片段注释，先分清完整示例与需要对象上下文的项目节选；运行标明可独立运行的组合示例，再修改输入观察结果。
2. 跟任务书完成一个小步骤，看到结果后再继续。按 LLM 调用、输出校验、Action、接口异常、窗口展示依次学习；第一周 ASR 继续复用，项目交付范围以任务书为准。
3. 卡住时记下“执行了哪一步、出现什么提示”，找对应同伴一起检查。

先在同一台 Linux 机器上配合，第二周[共同任务](../task/02_第二次任务/README.md)要求文字/语音进入真实 LLM，生成经校验候选或追问，并完成去重、超时取消与失败恢复。

## 三、最后交什么

每人交一份简短说明：操作步骤、看到的结果、三个问题的回答、还没解决的问题。接口同学汇总[共同记录](../task/02_第二次任务/验收记录模板.md)，无需三人重复写同一份长报告。

多轮对话、并发推理、持久化队列、完整断线恢复和机器人执行放到后续；本周必须完成任务书中的必要异常处理。负责人需要核对项目进度时，再看[项目基线](../task/阶段安排与项目基线.md)。
