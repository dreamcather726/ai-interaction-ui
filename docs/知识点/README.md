## 共同理解的四件事

1. **每个阶段只证明本阶段。** 发送完成、文件落盘、请求登记和真实识别成功不能混为一谈。
2. **身份比到达顺序可靠。** 两段输入的状态和文字可能交错，迟到结果仍归原请求。
3. **超时表示等待预算耗尽。** 对端可能仍在处理，先标未确认，不自动重发；没有查询就说明限制。
4. **验证需要分层。** 逻辑替身、真实通信、真实模型、跨设备和断网加载分别说明覆盖范围。

## 五天学习与实践节奏

| 时间 | 学习重点 | 同步项目产物 |
|---|---|---|
| 第 1 天 | 本岗位前置概念、输入和运行边界 | 实际版本、路径、模型、接口与缺项清单 |
| 第 2 天 | 异步调用／模型复用／事件循环 | 单段真实链路与最小显示 |
| 第 3 天 | 来源关联、连续处理、当前与历史 | 两段真实输入的一一对应记录 |
| 第 4 天 | 失败、超时、迟到与恢复 | 受控故障观察和限制 |
| 第 5 天 | 回答问题、互相讲解、他人复现 | 知识笔记、个人操作说明与联合记录 |

学习笔记写“自己的解释 → 一张图或一段伪代码 → 实际观察 → 尚存疑问 → 资料来源”。伪代码用于解释设计，不是可直接运行的项目实现。功能要求以[共同任务书](../task/02_第二次任务/README.md)为准，实际结果填入[验收记录模板](../task/02_第二次任务/验收记录模板.md)，阅读完成不等于功能验收通过。
