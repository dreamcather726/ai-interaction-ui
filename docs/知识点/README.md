## 二、怎样学习

1. 阅读知识点，运行短代码，再修改一两处观察输出。
2. 跟任务书完成一个小步骤，看到结果后再继续。摘要、分帧、超时和有界历史等先作为进阶练习，不要求把所有示例都加入本周程序；项目交付范围以任务书为准。
3. 卡住时记下“执行了哪一步、出现什么提示”，找对应同伴一起检查。

先在同一台 Linux 机器上配合，第二周[共同任务](../task/02_第二次任务/README.md)只要求两份真实录音能显示对应文字，以及一个简单失败例子。

## 三、最后交什么

每人交一份简短说明：操作步骤、看到的结果、三个问题的回答、还没解决的问题。接口同学汇总[共同记录](../task/02_第二次任务/验收记录模板.md)，无需三人重复写同一份长报告。

复杂队列、多线程、完整断线恢复、离线部署等放到后续阶段，不影响本周基础任务通过。负责人需要核对项目进度时，再看[项目基线](../task/阶段安排与项目基线.md)。
