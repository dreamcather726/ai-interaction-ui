# 第二次任务：机器人可视化与监控工程师

**本周小目标：** 做一个能显示识别状态和文字的小窗口。

先读[四个入门知识点](../../知识点/第二周/机器人可视化与监控工程师｜第二周专业知识自学清单.md)。第一周做过的小窗口可以直接接着用；没有完成的，先从空窗口开始。

## 一、窗口只放三样东西

```text
┌────────────────────────────┐
│ 状态：等待数据             │
│ 本次编号：还没有           │
│ 识别文字：                 │
│                            │
└────────────────────────────┘
```

使用 PySide6。先做一个状态标签、一个编号标签和一个文字区，不要求美化、分页、历史列表或录音按钮。

## 二、按四步完成

### 第 1 步：打开一个窗口

沿用第一周代码，或在参考项目 `robot_visualization` 包中添加窗口。请负责人协助确认依赖和启动入口。

本周统一新增入口为 `monitor_ui`，在包的 `setup.py` 中注册。窗口入口可以命名为 `monitor_ui = robot_visualization.monitor_ui:main`，这是本周要补的内容，原空包里还没有。

**完成标志：** 能按[共同步骤](README.md)启动窗口，看到“等待数据”，能正常关闭。

### 第 2 步：先用演示文字练习

先让窗口显示一条演示内容，例如“你好，机器人”，并在状态上明确写“DEMO 演示”。然后改成另一句话，练习更新显示。

**完成标志：** 会把文字写到控件里，不要求这一步接真实模型。演示成功不算真实识别通过。

### 第 3 步：接上真实状态和文字

向接口同学取得以下两个话题及对应消息类型：

| 接收什么 | 话题 | 消息类型 |
|---|---|---|
| 状态 | `/interaction/asr_status` | `robot_interfaces/msg/AudioProcessingState` |
| 文字 | `/interaction/asr_text` | `robot_interfaces/msg/RecognizedText` |

先用 QTimer 定时执行一次不等待的 ROS 消息处理（`spin_once(timeout_sec=0)`），每次回调只保存数据、更新显示。本周不要求新增工作线程。

`request_id` 是本次编号。无论先收到状态还是文字，都按编号对应；新编号开始显示时，先清空旧文字。旧编号的消息不要覆盖当前内容。

**完成标志：** 第一份录音能显示真实文字；第一份完成后，再发第二份，窗口显示第二份自己的文字。

### 第 4 步：补上简单提示

| 什么时候 | 窗口写什么 |
|---|---|
| 尚未收到消息 | 等待数据 |
| 正在识别 | 正在识别 |
| 成功并收到本次文字 | 识别完成，并显示文字 |
| 阶段已完成但文字还没到 | 等待本次文字 |
| 无语音或失败 | 显示实际原因，当前区不填旧文字 |
| 收到不认识的状态 | 状态未知 |

成功文字要同时检查 `success`、成功状态和非空 `text`；这些字段请接口同学一起说明。不要求背枚举数字，也不要写死一条“成功答案”。

**完成标志：** AI 同学测试文件不存在时，窗口能提示失败；等待数据时仍能拖动、关闭。关闭时停止自己的定时器和 ROS 节点，外部程序由对应同学用 Ctrl+C 结束。

## 三、交什么、怎样算完成

交一份简短说明：怎样启动、两个话题是什么、两份录音显示了什么、失败时显示什么、三个学习问题的回答。截图按负责人约定的位置保存。

基础通过要求见共同 W2-01～05。本岗位重点是两份真实文字不混用、失败有提示、窗口能正常关闭。复杂历史记录、进程重启过滤和断线恢复以后再学，本周不考核。
