# 第二次任务：机器人可视化与监控工程师

**任务名称：** 在现有包骨架中完成结构化识别状态与文字窗口。

**周期：** 第二周，5 个工作日；先看[共同安排](README.md)。

**配套学习：** [第二周知识清单](../../知识点/第二周/机器人可视化与监控工程师｜第二周专业知识自学清单.md)。

## 一、从哪里继续

参考项目 `robot_visualization` 当前只有包骨架，setup.py 没有可执行入口。第一周个人窗口若有未合入成果，先验收后复用；否则本周补齐最小窗口，不假定已有本地完整工作台。

在 `ai_interaction_ws/src/robot_visualization/` 开发，使用一种 GUI 框架 PySide6。向接口岗取得统一清单，订阅 `/interaction/asr_status` 和 `/interaction/asr_text`，不直接调用模型，也不再建立第二套转发。

## 二、需要做的事情

1. **交付最小可启动窗口。** 显示数据模式、等待／阶段、当前请求标识、文字、错误与历史；加可读的长文字区域。注册一个入口，建议 `monitor_ui = robot_visualization.monitor_ui:main`，并提供真实启动命令。该入口是本周新增交付要求，基线尚不存在。
2. **正确处理两个事件循环。** 最小程序可用 QTimer 周期执行 `spin_once(timeout_sec=0)`，回调只做轻量接收；已有线程方案也可复用，用信号在主线程更新控件。界面不等模型，不在 UI 线程同步等待服务。
3. **按请求合并状态与文字。** 用 `request_id` 建记录，保存其余来源字段；新请求文字未到时显示等待，不使用上次文字。已完成记录转入历史，迟到 A 段结果不覆盖正在显示的 B 段；当前与历史明确区分。
4. **处理重复、乱序与重启。** 阶段按 source_node／boot_id／request_id／event_seq 登记；不能比较阶段枚举数字来推断先后。文字按其请求和时间处理，不假定具有阶段序号。未知状态显示原值与未知提示。
5. **真实展示异常。** 成功且非空的 RecognizedText 才作为成功文字；无语音、失败、缺数据分别展示。`ASR_COMPLETED` 先于文字到达时显示等待文字；`confidence=-1` 不显示分数。没有模型健康／心跳来源时不画默认就绪图标。
6. **处理等待与恢复。** 接口岗当前 120 秒客户端超时不停止推理；窗口预算按现场记录，不自动重发，不声称机器人或 ASR 已停止。晚加入错过 Volatile 消息时明确无历史，当前没有 QueryAudio，不能生成查询成功提示。
7. **完成退出。** 停止自己的定时器与线程、销毁自己的 ROS 节点并退出；ASR 与转发由外部启动，按共同步骤停止，不擅自结束他人进程。

## 三、显示规则

| 实际情况 | 窗口显示 |
|---|---|
| 启动但未收到消息 | 尚未收到识别数据／状态未确认，不显示正常 |
| RECOGNIZING | 当前请求正在识别，不编造百分比 |
| ASR_COMPLETED、文字尚未到 | 识别阶段完成，等待对应文字 |
| 同请求成功且非空文字 | 显示实际文字及来源；不写机器人执行成功 |
| NO_SPEECH | 未识别到有效语音，本段无成功文字 |
| FAILED | 原错误码与可读原因，上一段文字保留时标历史 |
| 等待预算超时 | 等待超时、结果未确认；不自动重发 |
| 未知、断开或过期 | 显示未知／未确认和最后收到时间；阶段静默不单独证明进程掉线 |
| DEMO | 持续显示 DEMO 标记，不与真实验收混记 |

本周没有录音控制服务，不强制做开始／停止按钮；也没有 ProcessAudio 受理和 QueryAudio 运行端点，不展示假受理或补查。下一阶段新增这些能力后再增加按钮。

## 四、构建与启动要求

在参考项目 ROS 工作空间构建并加载；PySide6 在团队验证后锁定版本，记录安装方式，不批量复制此文档仓库环境快照：

```bash
source /opt/ros/humble/setup.bash
cd ~/ros2-logistics-interaction/ai_interaction_ws
colcon build --symlink-install --packages-up-to robot_visualization interaction_interface
source install/setup.bash
export ROS_DOMAIN_ID=173  # 与本轮接口／ASR 一致
# 完成上述新增入口后：
ros2 run robot_visualization monitor_ui
```

终端先检查真实接口，echo 用 Ctrl+C 退出：

```bash
ros2 topic info /interaction/asr_status --verbose
ros2 topic echo /interaction/asr_text robot_interfaces/msg/RecognizedText
```

终端都没数据时，记录 Domain、类型、QoS 和上游状态交接口岗排查；不在窗口临时读取“最新 WAV”或自己再触发一次识别。基线证据见[当前 setup.py](https://github.com/RoboNeuxs/ros2-logistics-interaction/blob/b878b982a08bf2533292a2a6aa5ae8611c0e1b90/ai_interaction_ws/src/robot_visualization/setup.py)。
