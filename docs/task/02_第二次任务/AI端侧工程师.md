# 第二次任务：AI 端侧工程师

**本周小目标：** 用已有模型，把两份真实录音识别成对应文字。

先读[本岗位知识点讲解](../../知识点/第二周/AI%20端侧工程师｜第二周专业知识自学清单.md)。基础启动命令见[共同步骤](README.md)，本周不训练或更换模型。

## 一、你负责哪一段

```text
接口同学交来录音 → 已有语音识别模型 → 真实文字或失败原因
```

参考项目的识别包叫 `ai_asr`，默认模型为 `paraformer-zh`。沿用已有环境，第一次准备环境可请负责人一起协助。

## 二、按四步完成

### 第 1 步：把已有模型启动起来

和接口同学按共同步骤启动一套识别程序。模型尚未下载或环境报错时，先解决这一项，再进入下一步。

如果已有本机模型配置，把共同步骤中终端 1 的启动命令替换为下面这一条；路径换成实际文件，**两条启动命令只选一条**：

```bash
ros2 launch interaction_interface interaction.launch.py config:=/absolute/path/interaction.local.yaml
```

**完成标志：** 模型完成加载；在后续真实录音测试中能够返回结果。只看到“程序启动”还不能当作识别通过。

### 第 2 步：识别第一份录音

让接口同学发 `a.wav`，你核对实际文字与录音内容。

**完成标志：** 文字基本符合录音内容。必须是模型实际识别出来的，不能用事先写好的句子代替。

### 第 3 步：不重启，识别第二份

等第一份完成，再让接口同学发 `b.wav`。和可视化同学一起确认窗口显示了第二份自己的文字。

**完成标志：** 同一个识别程序能顺序完成两份录音，两份结果没有混在一起。

### 第 4 步：看一个“文件不存在”的例子

两份真实录音都完成后，在已加载共同环境的新终端中执行一次测试。先确认下面路径没有文件；若有文件，换一个不存在的路径。

```bash
ros2 service call /ai/recognize_audio robot_interfaces/srv/RecognizeAudio \
  "{request_id: week2_missing, session_id: week2, segment_id: missing, input_context_id: week2, audio_path: /tmp/week2_file_not_found_20261110.wav}"
```

这条命令的意思是“请识别一个不存在的文件”，只用于失败演示。

**完成标志：** 返回 `success: false` 和文件不存在的原因；窗口提示失败，没有填入上一份文字。遇到问题就保存报错，和同伴一起处理。

## 三、交什么、怎样算完成

一份简短说明写清：实际启动命令、模型名称、两份录音的真实文字、失败测试看到的提示、三个学习问题的回答。

基础通过要求见共同 W2-01～05。本岗位重点是 W2-02～04。断网加载、完整版本锁定、性能对比和多任务同时识别以后再学，本周不考核。
