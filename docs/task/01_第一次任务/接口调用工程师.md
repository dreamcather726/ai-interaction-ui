## 任务基本信息

- **任务名称：** 接入麦克风原始录音，原样转发组内数据

- **建议周期：** 2～3 天

- **运行位置：** 香橙派完成录音采集，PC 机 Linux 虚拟机运行 ROS 2 接口节点

- **岗位文件夹：** `~/interface_engineer`（接口工程师），直接建在 Linux 用户主目录下

- **协作人员：** AI 端侧工程师、机器人可视化与监控工程师

## 一、本次目标

将香橙派麦克风采集的两段原始录音交给 AI 端侧工程师，并建立 ROS 2 转发节点，将 AI 端侧发布的状态和文字原样转发给可视化工程师。

**输入链：香橙派麦克风 → 接口工程师转交原始录音 → AI 端侧处理。**

**结果链：AI 端侧生成状态和文字 → 接口工程师原样转发 → 可视化界面显示。**

本岗位是组内数据的统一接入与传递人。音频重采样、声道转换、降噪、语音识别、文字修正和识别状态判断均由 AI 端侧工程师负责；本岗位不安装识别模型、不实现算法，也不根据文字内容判断任务含义。第一次只完成数据通路，搬运调度等功能放在后续任务。

### 创建、构建与启动示例

先加载项目现有 ROS 2 环境，再创建工作空间和录音资料目录：

```Bash
cd ~
mkdir -p interface_engineer/src interface_engineer/samples
cd interface_engineer
```

在 `src/` 下准备 `interaction_interface` 功能包、节点代码和依赖，录音及说明放在 `samples/` 中。以下命令是在代码完成后的目标启动方式。

终端一：构建并启动转发节点。

```Bash
cd ~/interface_engineer
colcon build --packages-select interaction_interface
source install/setup.bash
ros2 run interaction_interface audio_interface_node
```

终端二：同样先加载 ROS 2 环境，再检查输出；两个 `echo` 命令依次执行，查看一个后按 Ctrl\+C，再查看另一个。

```Bash
cd ~/interface_engineer
source install/setup.bash
ros2 node list
ros2 topic echo /interaction/asr_status std_msgs/msg/String
ros2 topic echo /interaction/asr_text std_msgs/msg/String
```

由 AI 端侧工程师提供明确标注 `DEMO` 的测试消息，先验证输入与输出的 `data` 完全一致；真实验证时由其启动识别节点并调用识别服务。本岗位不需要切换模式，使用同一个转发节点即可。

同一时间只运行一个接口节点。各终端沿用项目同一 ROS 2 发行版及通信配置，包括相同的 `ROS_DOMAIN_ID`，在操作步骤文档中记录实际值。样例字段参考 [String 定义](https://github.com/ros2/common_interfaces/blob/rolling/std_msgs/msg/String.msg)。
