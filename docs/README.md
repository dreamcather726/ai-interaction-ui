## 目录约定

```text
docs/
├── README.md              # 总入口
├── 指南/                  # 项目理解、实现顺序
├── 接口与部署/            # 公共协议、音频、设备和配置
├── 功能说明/              # 工作台、草稿、资料、查询
├── 验收/                  # 跨功能验收场景
├── 依赖/                  # 历史环境快照及使用边界
├── 知识点/                # 按周次分组、按“岗位｜周次”命名的学习清单
└── task/                  # 总任务书、分次任务、验收记录入口
```

同一文档只维护一份，不再向 `docs/` 根目录复制知识清单。第一周原文件按字节移入 `知识点/第一周/`，新增清单位于 `知识点/第二周/`，保持同一命名方式。项目文档使用相对链接；代码路径以仓库根目录为参照，命令另写工作目录。`task/本地原稿/` 保持本地忽略，原稿附件情况见[附件说明](task/附件/README.md)。

## 阅读时注意版本

本仓库 `ai-interaction-ui` 是可复用实现；用户指定的阶段参考项目是 [RoboNeuxs/ros2-logistics-interaction](https://github.com/RoboNeuxs/ros2-logistics-interaction)。两者不能直接视作同一完成度。参考仓库已核对至 `b878b98`，实际完成度与后续安排统一记在[项目基线](task/阶段安排与项目基线.md)。

指南描述完整实现路径，不表示每一周都要从头重写或启用全部功能。第二周复用第一周 ASR，新增 LLM 部署、任务理解 Action、接口编排与候选显示；公共字段以参考项目同版接口源码与现场构建版本为准，周任务与原总任务书冲突时按已登记的阶段安排执行。
